# The Funniest Office Joke, Judged Head to Head — make.fun entry

One joke about office life, one short line:

> I hit reply-all to ask to be removed from the thread. Forty-seven people replied-all to agree.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–200 character rule.
